## 🛠 Troubleshooting

### Export stuck at 99%

```powershell
# Clear cache
Remove-Item "$env:LOCALAPPDATA\CapCut\cache" -Recurse -Force

# Reduce export quality
# Export > Quality = Good (not Best) for faster processing

# Restart CapCut
taskkill /F /IM CapCut.exe
Start-Process "C:\Program Files\CapCut\CapCut.exe"
```

### Audio out of sync

```powershell
# Re-import media
# Delete clips from timeline, re-drag from media library

# Disable effects temporarily
# Right-click clip > Disable Effects

# Export at lower frame rate
# Export > Frame Rate = Match source (not 60fps)
```

### AI captions not working

```powershell
# Check internet connection
Test-NetConnection -ComputerName capcut.com -Port 443

# Re-login to account
# Settings > Account > Sign out > Sign in

# Use manual caption entry
# Text > Add Text > Type captions manually if AI fails
```
